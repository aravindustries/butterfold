# RTL
Describing a digital machine one excruciating line at a time.

> Built with :heart: by [Eloquencere](https://github.com/Eloquencere), [spacebiz24](https://github.com/spacebiz24), and [darshanram008](https://github.com/darshanram008)

## Directory Overview :open_file_folder:
| Name | Purpose |
| :--- | :--- |
| :file_folder: `bind/` | External binds for SVA & Coverage for HDL designs |
| :file_folder: `ip/` | Vivado IP folders with configuration information for instantiation |
| :file_folder: `mem/` | Memory (.mem) initialisation files used as lookup tables typically generated by code in the `scripts/` folder |
| :file_folder: `src/` | Primary design folder — FPGA board top-level files, HDL written from scratch, interface files |
| :page_facing_up: `rtl.tcl` | Declaratively specifies the top module and sources sub-directories' `.tcl` files into the EDA tool (Vivado) — part of `orchestrate_proj.tcl` |

**Not Implemented**

| Name | Purpose |
| :--- | :--- |
| :file_folder: `scripts/` | Python/Bash scripts for design development automation |
