Intentional mathematical changes
--------------------------------
- Large transform N: 128 -> 64
- Radix-2 stages: 7 -> 6
- Butterflies/stage implied by schedule: 64 -> 32
- Total butterflies: 448 -> 192
- Bit reversal: 7 bits -> 6 bits
- Twiddle index stride exponent: (6-stage) -> (5-stage)
- IFFT final normalization: >>7 -> >>6
- OFDM CP convention: 9/10 -> 4/5 samples
- OFDM TX subcarrier mapping preserved exactly at bins 1..12
- DFT12 fixed-point model left unchanged

Integration note
----------------
The new standalone vector/model filenames use fft64/ifft64 names. Existing RTL/testbenches
that still open fft128/ifft128 filenames will need a separate verification-infrastructure
update after the RTL redesign is complete. Do not alias 64-point vectors under 128-point
names unless that is a deliberate repository convention.
