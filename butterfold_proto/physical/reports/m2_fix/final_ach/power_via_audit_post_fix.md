## Organizer power-strengthening response

Reviewer concern: the main project supply was effectively powered through one
via. The pre-fix implementation merged all source PORTs at one single-cut
layer-transition stack. The ECO removes those supply-critical single cuts and
uses GF180 technology-generated multi-cut via masters; no raw cut polygons or
manual GDS patching are used.

- Metal2 / Metal3 / Metal4 widths: 1.000 / 1.000 / 1.600 µm.

AFTER:

- Every one of the 6 source PORTs uses
  `via2_3_3200_1200_1_3_1040_1040`, generated by `Via2_GEN_HH`,
  Metal2/Via2/Metal3, 1×3, 3 cuts. The final GDS contains exactly 3
  distinct 0.260 × 0.260 µm cuts at each source.

  x = 483.840, 637.440, and 791.040 µm.

  `Via3_GEN_HH`, Metal3/Via3/Metal4, 2×3, 6 cuts. The final GDS contains

- Minimum critical VDD cut count: 3 at each source, then 6 at each core entry.
- Supply-critical single-cut bottlenecks: 0.
